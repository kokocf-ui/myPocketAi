CHANGES IN v97
1. Improved web evidence ranking: sources independently returned by multiple configured providers receive a corroboration boost, without being treated as proof.
2. Added freshness-aware ranking for requests about current prices, recent developments, latest information and other time-sensitive facts. Parsed publication dates are exposed to the model with an approximate age; recent sources receive a ranking preference and very old sources are down-ranked.
3. Strengthened primary-source preference for legal/regulatory questions, including UK government and EU official legislation domains.
4. Added diagnostics for the number of cross-provider corroborated sources and whether freshness ranking was activated.
5. Preserved parallel Exa, Brave and Tavily calls, BRAVE_API_KEY naming, URL normalization/deduplication, original-page excerpts, evidence-aware status reporting, 10-language support, location isolation, transport and existing API behavior.
