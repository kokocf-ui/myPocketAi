# European locality name index for early address autocomplete

Source: [GeoNames](https://www.geonames.org/export/), via the published
[datasets/world-cities](https://github.com/datasets/world-cities) snapshot.
License: Creative Commons Attribution 4.0 (CC BY 4.0).
Generated: 17 November 2026.

This compact list contains 8699 populated places across Europe,
primarily cities with over 15,000 inhabitants plus administrative capitals.
It supplies **text-only city completions** for the first 1–2 letters after a
street-address comma, when the mapping provider supplies verified street and
door evidence for a country but no early city-autocomplete results.

The locality index has no verified building coordinates, house-number truth,
routes or schedules. Selecting any completion **must** trigger the existing
Geoapify search of the full address. Small towns not in this index still rely
on the ordinary mapping provider. No fixed addresses or itinerary examples
are used as lookup results.
